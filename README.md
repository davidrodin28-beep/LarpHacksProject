# BoxingPal

BoxingPal is a webcam-based boxing practice app. It tracks upper-body movement, counts arm extensions, jabs, crosses, and jab–cross combinations, and guides you through beginner jab and cross drills. Choose an Orthodox or Southpaw stance and follow the on-screen checkpoints or spoken instructions generated by ElevenLabs.

You can also invent a webcam game with NVIDIA Nemotron. The app generates rules based on your preferences and scores a timed round using the movements the tracker detects.

Camera frames are processed in your browser. Supabase handles accounts and password resets. Guest mode supports camera practice; sign in to use spoken instructions. Position feedback is a practice aid, not a complete assessment of boxing technique.

## Run locally

You need Python 3.11 or newer, an internet connection, and a browser with webcam access. The frontend and Python API run together on one local server.

### 1. Install dependencies

From the repository root:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e "./sportgen[dev]"
```

On Windows, use `py` instead of `python3` and `.venv\Scripts\python.exe` instead of `.venv/bin/python`.

### 2. Configure the app

Copy `.env.example` to `.env` and fill in your values. If `.env` already exists, keep it and edit the missing values.

| Variable | Purpose |
| --- | --- |
| `SUPABASE_URL` | Your Supabase project URL. |
| `SUPABASE_PUBLISHABLE_KEY` | Your Supabase public publishable key. |
| `ELEVENLABS_API_KEY` | Required for spoken coaching instructions. |
| `SPORTGEN_API_KEY` | Required to invent games with Nemotron. |
| `SPORTGEN_FAST_API_KEY` | Optional separate key for the fast generation engine. |

`ELEVENLABS_VOICE_ID` and `ELEVENLABS_MODEL_ID` are optional; the example file includes working defaults. Keep private keys in `.env`, which is ignored by Git.

In Supabase Authentication, enable email/password sign-in and allow these redirect URLs:

- `http://localhost:8000/login.html`
- `http://localhost:8000/reset-password.html`

### 3. Start the server

```sh
.venv/bin/python scripts/run_local.py
```

Open [http://localhost:8000](http://localhost:8000). The launcher loads `.env`, builds the frontend, and starts the website and API together. Stop it with `Ctrl+C`.

If port 8000 is busy, add `--port 8001` and update the Supabase redirect URLs to match. Restart the launcher after changing configuration or frontend files.

## Use the app

1. Log in or continue as a guest, then select **Start training**.
2. Choose a move and stance. Start the camera, frame your upper body, and make a fist followed by an open hand with each hand to finish setup.
3. Start guided practice and hold each checkpoint briefly. Arm extensions register at an elbow angle of at least 125° after returning to a bent position.
4. While signed in, select **Enable voice** and start guided practice. The coach reads only the current checkpoint, then reads the next step after you complete it. **Repeat current step** replays that checkpoint; mute or stop voice at any time.
5. Choose **Invent a sport** to generate a game, review its rules, and play a timed round.

ElevenLabs and Nemotron require internet access and their respective API keys. Voice synthesis uses ElevenLabs credits. Camera tracking runs locally in the browser.
